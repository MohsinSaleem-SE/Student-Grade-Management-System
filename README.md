# Student Grade Management System

A Python-based Student Grade Management System built using Object-Oriented Programming (OOP), Data Structures and Algorithms (DSA), functions, and core Python programming concepts.

## Overview

This project is designed to manage student records, courses, and grade calculations using Python. It demonstrates the practical application of programming concepts to organize student information and process academic data efficiently.

## Features

- Manage student records
- Store and retrieve student information
- Manage course details
- Calculate student grades
- Search and sort student records
- Validate user input

## Python Concepts Used

- **Object-Oriented Programming (OOP):** Classes, objects, encapsulation, and inheritance
- **Data Structures and Algorithms (DSA):** Lists, tuples, dictionaries, searching, and sorting
- **Functions:** Modular and reusable code
- **Control Flow:** Conditional statements and loops
- **Input Validation:** Handling user input correctly

## Technologies Used

- Python
- Object-Oriented Programming
- Data Structures and Algorithms

## How to Run

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in your terminal or VS Code.
4. Run the main Python file:

```bash
python main.py
```

**Note:** Replace `main.py` with your actual Python filename if it is different.
